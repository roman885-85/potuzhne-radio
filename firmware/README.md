# ПОТУЖНЕ РАДІО — прошивка для плати ES3C28P

ESP32-S3, екран 2,8″ IPS 240×320 на ILI9341V, ємнісний сенсор FT6336, звуковий кодек ES8311 з підсилювачем
FM8002E, слот microSD, 16 МБ флеш-пам'яті, 8 МБ PSRAM, зарядка акумулятора TP4054.

---

## 1. Файли

| Файл | Навіщо |
|---|---|
| `PotuzhneRadio-ES3C28P-update.bin` | програма — для оновлення через сторінку радіо, програму «Збірка» або `./flash.sh --app-only` |
| `PotuzhneRadio-ES3C28P-full.bin` | повний образ для першої прошивки кабелем (стирає налаштування) |
| `PotuzhneRadio-ES3C28P-bootloader.bin`, `-partitions.bin`, `-files.bin`, `boot_app0.bin` | частини повного образу |
| `web/app.js.gz`, `web/app.css.gz` | файли сторінки радіо |
| `VERSION` | номер версії, який `rebuild.sh` записує в прошивку |
| `rebuild.sh` | збирання (Mac) |
| `flash.sh` | прошивка кабелем (Mac) |

Бінарні файли в репозиторії не зберігаються — вони в релізі.

## 2. Прошивка кабелем

У плати **немає мікросхеми USB-UART** — роз'єм Type-C іде прямо в ESP32-S3, тож у режим завантаження її
переводять руками: від'єднати кабель → тримати **BOOT** → під'єднати кабель → відпустити BOOT.

```bash
./flash.sh                  # повний образ
./flash.sh --app-only       # лише програма; станції, мережі й налаштування лишаються
./flash.sh /dev/cu.usbmodem1101    # якщо порт не знайшовся сам
```

`--app-only` пише ще й `boot_app0.bin` у розділ otadata: після оновлення через сторінку радіо вантажиться
з другого розділу програми (app1), і без цього нова програма в app0 лишилася б невживаною.

Windows / Linux:

```bash
esptool --chip esp32s3 --baud 921600 write-flash -z --flash-mode dio --flash-freq 80m --flash-size 16MB 0x0 PotuzhneRadio-ES3C28P-full.bin
```

## 3. Розділи пам'яті

| Розділ | Адреса | Розмір |
|---|---|---|
| bootloader | 0x0 | 20 КБ |
| таблиця розділів | 0x8000 | |
| nvs | 0x9000 | 20 КБ |
| otadata | 0xe000 | 8 КБ |
| app0 | 0x10000 | 3 МБ |
| app1 | 0x310000 | 3 МБ |
| spiffs | 0x610000 | 2 МБ — сторінка, списки станцій і мереж, логотипи |
| coredump | 0x810000 | 64 КБ |

Два розділи програми — для оновлення через Wi-Fi: нова прошивка пишеться у вільний, і радіо перемикається на неї
після перезавантаження.

## 4. Виводи

| Вузол | Виводи |
|---|---|
| ILI9341V | CS 10, DC 46, SCLK 12, MOSI 11, MISO 13, підсвітка 45 |
| FT6336 | SCL 15, SDA 16, INT 17 (будить радіо з глибокого сну), RST 18 |
| ES8311 | MCLK 4, BCLK 5, LRCK 7, DOUT 8, DIN 6; I2C — ті самі 15/16 |
| FM8002E | GPIO1, **низький рівень вмикає підсилювач** |
| microSD | SDIO 4 біти: CLK 38, CMD 40, D0 39, D1 41, D2 48, D3 47 |
| Акумулятор | GPIO9 через дільник 1:2 |
| RGB-світлодіод | GPIO42 (WS2812) |
| Кнопка BOOT | GPIO0 |

Вільні виводи на роз'ємах звороту плати: Expand — **2, 3, 14, 21**; UART — **43 (TX0), 44 (RX0)**, 5 В, GND;
I2C — 3,3 В, GND, 15, 16. Зовнішній ЦАП I2S: BCLK 14, LRC 21, DOUT 2 (схеми — на сторінці радіо,
«Розробник → Аудіовихід»).

## 5. Що додано до yoRadio, щоб він запрацював на цій платі

- **Кодек ES8311** (`src/ES8311/`): yoRadio розрахований на «німий» ЦАП, а ES8311 без налаштування регістрів
  мовчить, і його дільники залежать від частоти потоку. Драйвер перенастроює їх при кожній зміні частоти.
- **MCLK** (`I2S_MCLK`): у yoRadio такого виводу не було; зафіксовано MCLK = 256 × частота дискретизації.
- **Сенсор FT6336** (`src/FT6336_Touchscreen/`): координати перераховуються з портретної системи панелі в екранні.
- **Картка пам'яті на SDIO** замість SPI, з відкатом в однобітний режим.
- `myoptions.h` з усіма виводами й `partitions.csv` під 16 МБ.

Далі — усе, що робить його ПОТУЖНИМ РАДІО: `src/extras/` (сон, будильник, ніч, батарея, світлодіод, обране,
проповіді, запис, логотипи, веб-API, живлення, версія), `src/menu/` (меню на екрані), нова сторінка
(`web/`), доробки бібліотеки звуку (перемотка проповідей через HTTP Range, перемотка M4A за таблицями кадрів,
справжня частота M4A).

## 6. Збирання

```bash
./rebuild.sh
```

Потрібні `arduino-cli` і ядро `esp32:esp32@3.3.3` (див. головний README). Скрипт збирає `../source/yoRadio`
власним набором бібліотек із `../build/sketchbook` (глобальні бібліотеки Arduino не чіпає), записує версію й час
збірки в прошивку, стискає файли сторінки й кладе готові образи сюди ж. Перша збірка — близько 13 хвилин.
