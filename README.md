# ПОТУЖНЕ РАДІО

Інтернет-радіо на платі **ES3C28P**: ESP32-S3, сенсорний екран 2,8″, кодек ES8311 із мікрофоном, картка пам'яті,
акумулятор. Грає радіостанції з інтернету, музику з картки й проповіді з сайту церкви, будить зранку, пише ефір
на картку. Керується дотиками, з браузера або програмами для Android, Windows і Mac. Нові версії приходять
на радіо самі — з цього репозиторію.

**Завантажити:** [останній випуск](../../releases/latest) — прошивка, файли сторінки й готові програми.

**За основу взято [yoRadio](https://github.com/e2002/yoradio) 0.9.693** (автор — e2002, ліцензія GPL v3): від нього —
ядро плеєра інтернет-радіо. Для цієї плати дописано драйвери кодека ES8311, сенсора FT6336 і картки на SDIO, а
інтерфейс на екрані, сторінку радіо, програми, проповіді, будильник, запис, мікрофон, звукову обробку, живлення й
оновлення з GitHub зроблено в цьому проєкті наново.

## Екран радіо

Увесь інтерфейс — згладжені шрифти й кнопки, темна тема з фірмовим жовтим. Сторінки меню в'їжджають зсувом,
списки гортаються пальцем з інерцією, від дотику розходиться хвиля. Дотик «притягується» до найближчої кнопки
чи повзунка — на маленькому екрані менше промахів. Класичне меню yoRadio лишилось: перемикач у «Параметрах».

### Головний екран

<img src="media/ekran-holovnyi.png" width="320" alt="Головний екран">

- **Шапка:** значок джерела (радіо чи картка — дотик перемикає), назва станції (довга — біжить), значки
  мікрофона, будильника, таймера сну й запису, батарея (від зарядника — зелена з блискавкою), сила Wi-Fi,
  кнопка **☰** — меню.
- **Картка «зараз грає»:** логотип станції (радіо знаходить логотипи саме), пісня й виконавець, бітрейт і формат,
  міні-спектр. Дотик по картці — пауза / грати; довгий дотик або рух пальцем угору-вниз — список станцій.
- **Годинник** із секундами, день тижня, дата, погода зі значком.
- **Спектр** над гучністю — справжній, з аналізу звуку (32 смуги, 50 Гц … 16 кГц): у тиші стоїть, шкала сама
  підлаштовується під гучність станції.
- **Гучність** — повзунок на всю ширину, краї «липкі» (легко поставити нуль чи максимум); змінюється плавно,
  без клацань.
- Запуск і перемикання станцій — через затухання й наростання звуку.

### Проповідь

<img src="media/ekran-propovid.png" width="320" alt="Проповідь з великою обкладинкою">

Під час проповіді з сайту — велика обкладинка, назва на кілька рядків, проповідник і дата. Під нею — годинник і
перемотка: доріжка з поточним місцем і тривалістю, кнопки попередньої й наступної. Дотик по обкладинці — пауза;
зупинена проповідь продовжується з того самого місця.

### Меню

<img src="media/menu-pult.png" width="320" alt="Меню-пульт">

- **Швидкі кнопки:** **Сон** (дотиками по колу 15 → 30 → 60 → 90 хв → вимк., видно, скільки лишилось),
  **Будильник** (видно час; дотик — налаштування), **Запис** ефіру на картку, **Радіо / Картка** — джерело.
- **Яскравість** екрана.
- **Розділи:** Станції, Обране, Проповіді, Звук, Екран, Параметри, **Оновлення** (жовте з червоною крапкою, коли
  вийшла нова версія) і Живлення.

### Список станцій

<img src="media/stantsii.png" width="320" alt="Список станцій">

- Логотип або літери назви, номер і адреса станції; зірка — станція в обраному.
- Та, що грає, — жовта, праворуч живі риски спектра.
- Прокрутка з інерцією й пружиною до рядка; швидка — пальцем по правому краю (з'являється номер рядка).
- Дотик — увімкнути станцію; довгий дотик — повна назва.
- На картці пам'яті тут же — треки: назва файлу, тека, формат.

### Обране

<img src="media/obrane.png" width="320" alt="Обране">

Шість швидких кнопок із логотипами. Дотик по порожній — додати станцію, що грає; по заповненій — увімкнути;
утримати — прибрати. «Показувати на головному» — кружечки обраного під годинником.

### Проповіді

<img src="media/propovidi.png" width="320" alt="Список проповідей">

Увесь архів проповідей із сайту церкви: назва, проповідник, дата, тривалість. Та, що грає, позначена жовтим.
Дотик — слухати; обкладинка й перемотка — на головному екрані.

### Будильник і сон

<img src="media/budylnyk.png" width="320" alt="Будильник: барабан часу">

- **Барабан часу** — години й хвилини крутяться пальцем, як у телефоні.
- **Щодня або в будні.** Спершу дзвіночок, потім станція наростає за пів хвилини (не тихіше за розумний мінімум).
  Рухнули гучність — будильник більше не втручається.
- **Будить і вимкнене радіо:** перед сном радіо ставить таймер, тихо (без заставки й підсвітки) прокидається
  трохи раніше, звіряє час із мережею й дзвонить у свій час.
- **Таймер сну** — звук плавно затихає наприкінці.

### Звук: еквалайзер і обробка

<p>
<img src="media/ekvalaizer.png" width="320" alt="Еквалайзер">
<img src="media/obrobka.png" width="320" alt="Обробка звуку">
<img src="media/pid-kimnatu.png" width="320" alt="Поправка під кімнату">
</p>

- **Еквалайзер на 10 смуг** (31 Гц … 16 кГц): смуги тягнуться пальцем, пресети «рівно», «голос», «музика», «бас»,
  «ніч», «яскраво», «тепло» і свій. Зелені крапки — поправка під кімнату.
- **Обробка:** захист маленького динаміка від низу, якого він не відтворює (м'який чи сильний); віртуальний бас
  (гармоніки замість зрізаного низу); тонкомпенсація на тихій гучності; баланс; обмежувач замість хрипу від
  перевантаження.
- **Під кімнату:** радіо грає тони й слухає себе вбудованим мікрофоном. Спершу перевіряє, чи мікрофон і динамік
  не спотворюють звук, тоді ставить поправку, міряє ще раз уже з нею й доправляє; якщо рівніше не стало —
  поправка не вмикається.

### Екран

<img src="media/ekran.png" width="320" alt="Налаштування екрана">

Яскравість; **нічний режим** за розкладом (початок і кінець — барабаном, своя яскравість уночі); без зарядника й
дотиків екран пригасає через обраний час; стан батареї; світлодіод WS2812 на платі — стан радіо або «в такт музиці».

### Мікрофон, хлопки й присутність

<p>
<img src="media/mikrofon.png" width="320" alt="Мікрофон">
<img src="media/khlopky.png" width="320" alt="Хлопки й стук">
<img src="media/prysutnist.png" width="320" alt="Присутність">
</p>

- **Мікрофон:** увімкнути, чутливість, «слухати й під час звуку» — радіо віднімає власний звук (кодек віддає
  вихід ЦАП другим каналом), тож удари в пісні командами не стають. Поки мікрофон слухає, у шапці горить значок;
  звук нікуди не передається.
- **Хлопки й стук** по корпусу: два чи три — пауза, наступна станція, гучність тощо (дії на вибір), окремо для
  хлопків і стуку, зі своєю чутливістю.
- **Присутність:** таймер сну затихає раніше, коли в кімнаті давно тихо; голос будить екран, а довга тиша гасить.

### Параметри

<p>
<img src="media/parametry.png" width="320" alt="Параметри">
<img src="media/chasovyi-poias.png" width="320" alt="Часовий пояс">
</p>

Wi-Fi (пошук мереж, пароль на екранній клавіатурі, відомі мережі), мікрофон і жести, часовий пояс (барабаном),
автостарт після ввімкнення, класичне меню, **Оновлення**, **Про радіо** (версія, мережа, сигнал, потік, погода,
батарея, пам'ять), **Живлення**, **Розробник**.

### Оновлення

<p>
<img src="media/onovlennia-propozytsiia.png" width="320" alt="Пропозиція оновитись">
<img src="media/onovlennia.png" width="320" alt="Сторінка «Оновлення»">
</p>

Радіо двічі на добу перевіряє випуски в цьому репозиторії. Вийшла нова версія — на головному екрані з'являється
«Є нова версія» з першим рядком опису: **«Оновити»** або **«Пізніше»** (тоді — «Меню › Оновлення»). Сторінка
«Оновлення» показує версію в радіо й на GitHub, опис змін, кнопки «Перевірити зараз» і «Встановити». Під час
встановлення на весь екран — хід: кільце з відсотками, мегабайти, швидкість. Станції, мережі, обране й налаштування
лишаються. Перемикач **«Пробні версії»** — отримувати попередні випуски раніше за всіх.

### Живлення

<img src="media/zhyvlennia.png" width="320" alt="Живлення">

**Перезавантажити** або **Вимкнути** — треба утримати кнопку, поки замкнеться коло (випадково не вимкнеш).
Вимкнене радіо спить глибоким сном і майже не бере заряду; вмикається дотиком до екрана або будильником.

### Розробник

<p>
<img src="media/rozrobnyk.png" width="320" alt="Розробник">
<img src="media/zvuky.png" width="320" alt="Заставка й звуки">
<img src="media/zvuky-hucnist.png" width="320" alt="Гучність кожного звуку й кнопка «прослухати»">
<img src="media/audiovykhid.png" width="320" alt="Аудіовихід">
</p>

Що показувати на екрані (батарея, IP-адреса), картка пам'яті, пошук логотипів станцій наново. **Заставка й звуки:**
анімована заставка запуску з басовим акордом і гучність привітання; звуки подій (дотик, жест, мережа з'явилась
і зникла, таймер сну, будильник, батарея сідає) — загальна гучність і повзунок для кожного звуку окремо, а біля
кожного кнопка ▶ — прослухати звук одразу з новою гучністю. **Аудіовихід:** вбудований кодек ES8311 або зовнішній ЦАП — PCM5102A,
UDA1334A, MAX98357A — зі схемами підключення без паяння.

## Сторінка радіо в браузері

Адреса — на екрані «Про радіо» або `http://potuzhne-xxxx.local/`. Та сама сторінка відкривається в програмах для
Android, Windows і Mac. Ліворуч — розділи з коротким описом, унизу — завжди видимий міні-плеєр.

### Плеєр

<img src="media/web-pleier.png" width="820" alt="Сторінка: плеєр">

Що грає, логотип, перемикання й гучність; джерело (радіо чи картка) і проповіді; обране; таймер сну й запис ефіру.

### Станції

<img src="media/web-stantsii.png" width="820" alt="Сторінка: станції">

Список радіостанцій і треків картки з пошуком. Додати, змінити, пересунути, видалити; **пошук у каталозі станцій**
(radio-browser.info); **імпорт** CSV, M3U, PLS, JSON і **експорт**; свій логотип станції.

<img src="media/web-holos.png" width="410" alt="Сторінка: голосові команди">

- **Голосові команди** — що радіо розуміє в програмах для Android і Mac («наступна», «гучність 30», «грай Хіт FM»…),
  з перевіркою фрази.
- **Оновлення** — **«З GitHub»** (перевірка й встановлення нової версії з ходом, як на радіо), прошивка й файли
  сторінки з файлу, резервні копії станцій, обраного й мереж.
- **Система** — грати після ввімкнення, ім'я в мережі, telnet, сторож, перезавантажити й вимкнути.
- **Розробник** — що показувати, заставка й звуки подій: гучність кожного звуку, «Прослухати» і **свій звук**
  замість стандартного. Підходять MP3 і WAV (також OGG, M4A, FLAC) до 20 МБ; сторінка сама переводить звук у формат
  радіо — WAV моно, 22 050 Гц, 16 біт, до 10 с (≈ 440 КБ), вирівнює гучність і м'яко гасить кінець. Далі — аудіовихід.

Ще є **Wi-Fi** (пошук, підключення без перезавантаження) і **Час і погода** (часовий пояс, сервери часу, погода
за координатами).

## Встановлення

### 1. Прошити плату (один раз, кабелем)

Файли — у [випуску](../../releases/latest). Якщо плата не входить у режим прошивки сама: від'єднайте кабель,
натисніть і тримайте **BOOT**, під'єднайте кабель, відпустіть BOOT.

**На Mac** — з теки `firmware` цього репозиторію (потрібен esptool з ядра ESP32 для Arduino або `pip3 install esptool`):

```bash
./flash.sh
```

**На Windows / Linux** — файл `PotuzhneRadio-ES3C28P-full.bin`:

```bash
esptool --chip esp32s3 --baud 921600 write-flash -z --flash-mode dio --flash-freq 80m --flash-size 16MB 0x0 PotuzhneRadio-ES3C28P-full.bin
```

Або програмою **«Збірка ПОТУЖНОГО РАДІО»** (див. нижче). Повний образ стирає станції, мережі й налаштування —
далі радіо оновлюється без цього.

### 2. Підключити до Wi-Fi

Поки мережі немає, радіо саме відкриває **список мереж** (гортається пальцем). Виберіть свою, наберіть пароль на
екранній клавіатурі — радіо підключається одразу, без перезавантаження, і каже результат: «готово», «невірний
пароль» або «мережі не видно». Радіо працює з мережами **2,4 ГГц** і пам'ятає до п'яти; якщо звичної немає в
ефірі, само перебирає решту.

### 3. Керувати

- **На радіо:** дотик по картці — пауза; рух пальцем чи довгий дотик — список станцій; **☰** — меню.
- **У браузері:** адреса з «Про радіо» або `http://potuzhne-xxxx.local/`.
- **Програмами** — вони знаходять радіо в мережі самі (див. [Програми](#програми)).

## Оновлення

- **Само:** радіо перевіряє [випуски](../../releases) двічі на добу й пропонує оновитись — «Оновити» на
  головному екрані або «Меню › Оновлення». Хід видно на екрані й на сторінці; станції й налаштування лишаються.
- **Зі сторінки:** «Оновлення» → «З GitHub», або файл `PotuzhneRadio-ES3C28P-update.bin` → «Оновити радіо».
- **Програмою «Збірка ПОТУЖНОГО РАДІО»** — «Залити прошивку» / «Залити сторінку» по Wi-Fi.
- **Кабелем:** `./flash.sh --app-only` — лише програма, списки лишаються.

> З версії **1.3 і раніше** радіо ще не вміє оновлюватись саме: прошийте `update.bin` через сторінку — далі
> оновлення прийдуть самі. Анімована заставка й звуки подій потребують нової таблиці розділів — вони з'являться
> після прошивки `full.bin` (вона стирає налаштування: спершу збережіть резервну копію на сторінці).

## Програми

Знаходять радіо в мережі самі, адресу вводити не треба. Показують ту саму сторінку радіо — кожне поліпшення
сторінки одразу є скрізь.

| Програма | Файл у випуску | Як поставити |
|---|---|---|
| Android 5.0 і новіші | `PotuzhneRadio-Android.apk` | Відкрийте файл на телефоні й дозвольте встановлення з цього джерела. На старих Android оновіть «Android System WebView». |
| Windows 10/11 | `PotuzhneRadio-Windows.exe` | Просто запустіть. Якщо Windows попередить — «Докладніше» → «Все одно запустити». Потрібен WebView2 (у Windows 11 є завжди). |
| macOS 13 і новіші | `PotuzhneRadio-Mac.zip` | Розпакуйте й перетягніть у «Програми». Перший запуск — правою кнопкою → «Відкрити». |

У програмах для Android і Mac — **голосові команди**: кнопка з мікрофоном угорі сторінки.

## Збирання з вихідного коду

<img src="media/zbirka.png" width="420" alt="Програма «Збірка ПОТУЖНОГО РАДІО»">

**Програмою** (найпростіше): «Збірка ПОТУЖНОГО РАДІО» для Mac (`PotuzhneRadio-Builder-Mac.zip`) або Windows
(`PotuzhneRadio-Builder-Windows.zip`). Номер версії, «Зібрати», журнал — і одразу заливка на радіо по Wi-Fi.
Версія для Windows при першому запуску сама завантажує інструменти (близько 1 ГБ); версії для Mac потрібна тека з
цим репозиторієм (`git clone`).

**Терміналом на Mac:**

1. [arduino-cli](https://arduino.github.io/arduino-cli/) і ядро ESP32 3.3.3:
   ```bash
   arduino-cli core update-index --additional-urls https://espressif.github.io/arduino-esp32/package_esp32_index.json
   arduino-cli core install esp32:esp32@3.3.3 --additional-urls https://espressif.github.io/arduino-esp32/package_esp32_index.json
   ```
2. Зібрати (номер версії — у `firmware/VERSION`):
   ```bash
   cd firmware && ./rebuild.sh
   ```
   Перша збірка — близько 13 хвилин, наступні — кілька.
3. Готове — у `firmware/`: `PotuzhneRadio-ES3C28P-update.bin` (оновлення), `-full.bin` (повний образ), `web/`
   (файли сторінки).
4. Випуск на GitHub, звідки радіо оновлюються: `tools/release.sh <версія> <опис>` (`--beta` — попередній;
   `--promote <версія>` — зробити його випуском для всіх).

Програми-клієнти: `apps/*/build.sh` (Mac — Command Line Tools; Windows — .NET, збирається на Mac; Android — Android
SDK, без Gradle).

## Що де лежить

| Тека | Що там |
|---|---|
| `source/yoRadio/src/m2/` | інтерфейс на екрані: рушій (малювання смугами через DMA, згладжені фігури й шрифти, сторінки, прокрутка, хвиля), головний екран, меню, список станцій, оновлення |
| `source/yoRadio/src/extras/` | дописане: будильник і сон, живлення, звукова обробка (`yoDsp`), спектр, мікрофон і жести, звуки подій, заставка, проповіді, запис, логотипи, веб-API, оновлення з GitHub (`yoOta`) |
| `source/yoRadio/web/` | сторінка радіо (`app.js`, `app.css`) |
| `source/yoRadio/assets/` | звуки подій і заставка (розділ ресурсів на флеш) |
| `build/sketchbook/libraries/` | бібліотеки, з якими збирається прошивка |
| `firmware/` | збирання й прошивка, опис плати й розділів пам'яті |
| `apps/` | програми: `mac-client`, `mac-builder`, `windows-client`, `windows-builder`, `android-client`, спільний `shared` |
| `tools/` | випуск (`release.sh`), шрифти, звуки й заставка (`make_*.py`), перевірки через USB (`selftest.py`, `gesturetest.py`, `exttest.py`, `listtest.py`, `cmd.py`, `screenshot.py`) |
| `media/` | знімки для цього опису |

Про плату, розводку виводів і розділи пам'яті — у [firmware/README.md](firmware/README.md).
